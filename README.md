# Nicholas Ngesa — Software Engineer

A responsive personal portfolio for sharing Nicholas Ngesa's software projects, skills,
and ways to connect.

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server.
The site uses plain HTML, CSS, and JavaScript and has no build step or dependencies.

## Customize

- Edit the introduction, project cards, and skills in `index.html`.
- Replace `images/nicholas-ngesa.jpg` with a square head-and-shoulders portrait; the hero displays it in a circular frame.
- Update the responsive styling in `styles.css`.
- The mobile navigation, interactive project deck, and footer year are handled in `script.js`.
